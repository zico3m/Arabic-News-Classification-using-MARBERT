## Arabic News Classification using MARBERT
This project focuses on building an advanced Arabic News Classification system leveraging state-of-the-art Natural Language Processing (NLP) techniques. By fine-tuning the MARBERT model—a transformer-based model specifically pretrained on modern Arabic dialects and Modern Standard Arabic (MSA)—the system accurately categorizes Arabic news articles into their respective domains.
## Key Features
- Transformer-Based Architecture: Utilizes MARBERT from Hugging Face for deep contextual understanding of Arabic text.
- Data Processing Pipeline: Comprehensive preprocessing scripts built with pandas, scikit-learn, and Hugging Face datasets for tokenization, cleaning, and formatting.
- Fine-Tuning & Evaluation: Implements robust training loops using PyTorch and Hugging Face Trainer API, complete with performance evaluation metrics.
- Deployment Ready: Easily exportable and hosted model compatible with the Hugging Face Hub.

## Tech Stack
**- Language:** Python
**- Libraries & Frameworks:** PyTorch, Transformers (Hugging Face), Datasets, Scikit-Learn, Pandas, NumPy
**- Model: MARBERT:** UBC-NLP/MARBERT
